# Fonts

IBM Plex Sans (400, 500, 600, 700) and IBM Plex Mono (400, 500, 600) are bundled in
`design/src/main/res/font/` under the SIL Open Font License 1.1 (`IBM-Plex-OFL-1.1.txt`).
`MANIFEST.sha256` pins the exact files; check with `cd design/src/main/res/font && sha256sum -c ../../../../../tools/fonts/MANIFEST.sha256`.
